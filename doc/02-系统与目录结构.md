# 系统与目录结构

## 1. 总体链路

```text
胶囊 TX
  摄像头 + CX93510 JPEG + ADXL362 + nRF52832
                 │ 2.4 GHz Radio，当前 2400 MHz，2 Mbit/s
                 ▼
接收 RX
  nRF52832 + RF1662 12路天线 + 图片重组 + DeviceInfo
                 │ UART 1 Mbit/s
                 ▼
STM32F103RET6
  协议解析 + RTC + SD存储 + PC数据转发
```

## 3. 无线公共参数

| 参数 | 当前值 | 说明 |
| --- | ---: | --- |
| 频段 | 2.4 GHz | 用户需求中的“2400M通讯” |
| 中心频率 | 2400 MHz | TX/RX均配置 `RADIO_FREQUENCY_MHZ=2400` |
| nRF频率偏移 | 0 | `2400-2400` |
| Radio模式 | 2 Mbit/s | TX/RX必须一致 |
| 固定Radio载荷 | 254字节 | 图像和控制包统一长度 |
| 图片周期 | 500 ms | `IMAGE_PERIOD_MS` |
| 常态SN广播周期 | 500 ms | `SN_BROADCAST_PERIOD_MS` |
| TX ACK接收窗口 | 30 ms | END之后短时间开RX |

## 4. 三个工程的职责边界

### TX

负责生成数据：保存胶囊SN、周期唤醒、采集JPEG和加速度、拆分Radio包、等待ACK。TX不负责选择天线；只有收到RX的合法扫描请求后，才暂停图片并快速广播SN。

### RX

负责接收质量：绑定SN过滤、RF1662天线切换、RSSI统计、候选排序、图片重组、128字节设备信息生成。天线号在代码内部为0～11，对外设备信息为1～12。

### STM

负责系统汇聚：通过USART2接收RX数据，补充STM版本、芯片ID、运行时间、RTC和最终JPEG长度，通过SDIO/FatFs存储，并通过USART3向PC发送。
