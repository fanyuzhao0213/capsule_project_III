# TYGD31 接收显示工具（Python + Qt）

> 两个 Tab：
> 1. **实时串口（UART3）** — 接 STM32 串口 3，实时显示收到的 JPEG 图像
> 2. **U 盘文件（.YS）** — 浏览 SD 卡上的 `Y<SN>.YS` 文件，按帧解码显示

---

## 1. 安装

```bash
cd tools/tygd31_viewer
pip install -r requirements.txt
```

依赖：

- **PyQt5** — GUI
- **pyserial** — 串口通信

Python 3.7+。

---

## 2. 运行

```bash
python main.py
```

启动后界面分两个 Tab：

### Tab 1：实时串口（UART3）

```
+-----------------+-------+----------+-----------------+--------+
| 端口: COM5  ▼   | 波特率: 1000000 ▼ | [刷新] [打开串口] |
+-----------------------------------------------------------+
| [图像显示区]                | 设备信息 / 事件日志      |
|                             |                          |
+-----------------------------+--------------------------+
```

**使用步骤**：

1. 用 USB 转 TTL / USB 转 UART 线把 STM32 UART3 接到电脑
2. 选择端口（如 `COM5`、`/dev/ttyUSB0`）
3. 波特率选 `1000000`（默认 1 Mbps，与 STM 端一致）
4. 点击 **「打开串口」**
5. STM 上电后，JPEG 图像会实时显示在左侧
6. 右侧 **设备信息** 显示该帧的版本号、SN、长度、RTC 时间等
7. **「保存当前图像」** 可保存为 `.jpg`

### Tab 2：U 盘文件（.YS）

```
+--------------------+--------------------------------------+
| .YS 文件列表       | [上一帧] 5 / 23 [下一帧]            |
|                    +--------------------------------------+
| - Y1234....YS      | [图像显示区]                         |
| - Y5678....YS      |                                      |
|                    +--------------------------------------+
|                    | 设备信息                             |
+--------------------+--------------------------------------+
```

**使用步骤**：

1. 把 STM32 的 SD 卡取出，用读卡器插电脑
2. 点击 **「选择目录…」**，选 SD 卡的根目录（`E:\`、`/media/user/SDCARD` 等）
3. 左侧自动列出所有 `Y*.YS` 文件
4. **双击** 文件名 → 右侧开始解析并显示第一帧
5. **上一帧 / 下一帧** 浏览所有图像
6. **「导出当前帧为 JPG」** 或 **「导出全部帧为 JPG…」** 批量导出

## 4. 协议参考

### 4.1 UART3 帧格式（STM → PC）

```
+--------+--------+--------+--------+--------+--------+--------+
| 0xFF   | 0x55   | 0x12   | 0x34   |  cmd   | lenHI  | lenLO  |  ← 7 字节头
+--------+--------+--------+--------+--------+--------+--------+
| data[0]..data[N-1]                                              |  ← N 字节数据
+-----------------------------------------------------------------+
| CRC8                                                            |  ← 1 字节校验
+-----------------------------------------------------------------+
```

- `cmd = 0x81`：图像数据（payload = JPEG header 686B + JPEG data + DeviceInfo 128B）
- `cmd = 0x98`：ASCII 文本（如 `TFC:12345 KB`）

### 4.2 .YS 文件格式（SD 卡）

```
文件名: Y<7字节SN>.YS
帧大小: 20064 字节（128 帧头 + 20000 数据上限）

文件布局:
  +------------------------+
  | 200640 字节文件头       |  ← 含 "DS\0\0\0\0\0\0\0\0" + 0xFF 0x55 0x12 0x34
  +------------------------+
  | 帧 1 (20064 字节)      |  ← JPEG 数据 + 设备信息
  +------------------------+
  | 帧 2 (20064 字节)      |
  +------------------------+
  | ...                    |
  +------------------------+
```

## 5. 常见问题

### 串口打不开

- 检查 USB 转串口驱动是否安装
- Windows：到「设备管理器」看 COM 端口号
- Linux：`ls /dev/ttyUSB*`，需要当前用户在 `dialout` 组

### JPEG 解码失败

- 帧可能不完整（丢包）
- 检查 STM 端是否在 TX 端丢包后能完整重发
- 把 `config.h` 的 `IMAGE_REPEAT_SEND_ENABLED` 设为 1 提高抗丢包

### U 盘文件读取为空

- 确认目录里有 `Y*.YS` 文件
- 确认文件名后缀是大写 `.YS`
- 确认 SD 卡被正常挂载（不是写保护）
